## How to read this register

- **Severity**: P0 launch blocker (exploit / state loss); P1 major defect or trust problem; P2 clear
  usability/readability problem; P3 polish. A *test hypothesis* keeps the severity it would have if
  it turns out true.
- **Cause**: `Observed` = seen in the frames; `Code` = confirmed by reading the source today;
  `Suspected` = a hypothesis that still has to be proven. Nothing below is marked a confirmed bug
  unless the code itself shows it.
- **Disposition**: fix / test (prove or disprove first) / keep (strength to preserve, regression
  guard) / defer / excluded-by-approval (settings redesign, weapon fusion / new evolution system,
  historical score deletion, price or Robux changes without owner OK).
- **Role**: owner from the brief's ownership table (CORNER, CHOICE-SERVER, UISTATE, HUD, TITLE,
  ECON, FLOW, ENEMY-ART, WORLD-ART, COPY, SAFETY, PERF, REWARD, UPGRADE-UI, RESULTS, DUO-MENU).
- **Status**: every entry starts `open`. Owners update Status/Result with PASS / FAIL / BLOCKED and
  what was actually exercised (offline preview, Lune sim, Studio, device, two clients).

## Which build the recordings show (read before claiming anything is already fixed)

The recordings are not of current `main`. Markers in the frames:

- The elite toast "An elite Shielded Mite leads the wave!" (long/492s.jpg) existed in
  `EnemySpawner.lua` up to the full-game sweep (9b621d7, 2026-10-03). The audit commit cb15708
  (2026-10-04 00:04 UTC) removed it and folded elites into the one-per-wave toast.

  screen rebuilt in the Home + retention update (83be6c9, 2026-10-04 18:24 UTC).

**possibly fixed / changed: verify** below. That includes the elite toast wording, merged level-up
panels and card weights (f3a7b25), NEXT GOAL on results (5afe89a), the home screen (83be6c9),
first-run welcome, economy changes (KillGoldChance, StageClearBonus 300, survival gold), the
input-aware chest key label (6dfa65e) and the Hero Mastery update (660335a). Several things the
recordings show had already shipped *before* the recording, so they did not fix the matching
